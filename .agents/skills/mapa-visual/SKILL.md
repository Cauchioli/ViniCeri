# `/mapa-visual`: Mapa Visual de Cliente & Organização Leve do OneDrive

Sempre que o Dr. Vinícius Cerineo pedir para gerar uma **organização visual**, **planejamento visual de pasta de cliente** ou organizar o OneDrive sem pesar no computador, leia e execute integralmente as diretrizes de:

`50-skills-operacionais/07_skill_mapa_visual_cliente_e_onedrive.md`

## Resumo de Execução Rápida:
1. Identifique a pasta do cliente no OneDrive (`Clientes Fixos` ou `Processos`).
2. Mapeie a estrutura de arquivos e subpastas de forma leve (listagem de diretório + leitura cirúrgica apenas dos documentos-chave).
3. Gere um arquivo HTML executivo standalone (`MAPA_VISUAL_E_PLANEJAMENTO_{CLIENTE}.html`) com visual editorial de alto padrão (pronto para mostrar na tela ao cliente ou exportar em PDF com 1 clique).
4. Caso o pedido seja para organizar múltiplas pastas do OneDrive, opere estritamente em **lotes leves (5 a 10 pastas por vez)** ou via script Python determinístico para não sobrecarregar a memória do computador.
