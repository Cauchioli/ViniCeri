## Como usar este arquivo

A skill foi construída sem nenhuma identidade pessoal ou de escritório. O mecanismo de personalização está aqui: ao preencher os campos abaixo, você dá à skill o seu repertório, o seu tom e os seus pontos de atenção. **Nada neste arquivo altera a metodologia** — os demais módulos permanecem intactos. Este arquivo só calibra como o ato/parecer soa e o que a skill já sabe sobre como você trabalha.

Campos não preenchidos são simplesmente ignorados. Não invente dado para preencher: campo vazio é melhor que campo falso (ver `_licoes-aprendidas.md`, L-002).
