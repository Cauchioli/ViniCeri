# Sub-skill: Devil's Advocate

## 1. PROPÓSITO
Atacar construtivamente uma tese ou decisão estratégica **antes** de fixá-la, produzindo a lista de fraquezas que o próprio operador precisa resolver antes de seguir — para que a tese chegue à minuta já endurecida.

## 2. QUANDO ACIONAR
- **Modos:** DIAGNÓSTICO (antes de fechar o diferential), ESTRATÉGIA (antes de fixar o CoA primário).
- **Ponto do fluxo:** logo após o operador formular a tese candidata, antes de declará-la escolhida.
- **Condições de entrada:** existe uma tese articulada (não um tema vago).
- **Anti-gatilhos:** não acionar sobre peça já redigida (isso é `juiz-externo`); não acionar para simular a instituição respondendo (isso é `tensionamento-adversario`).

## 3. ENTRADA ESTRUTURADA
- Obrigatório: a tese candidata em uma frase + os fatos que a sustentam + a prova invocada.
- Opcional: as teses concorrentes já descartadas.
- Validação: se a tese é genérica demais para ser atacada ("o contrato é abusivo"), pedir refinamento antes (qual encargo, qual cláusula, qual parâmetro de abusividade).

## 4. PROCESSAMENTO
Para a tese candidata, gerar — em primeira pessoa cética, sem suavizar:
1. **Ponto cego fático** — qual fato a tese assume e não está provado? (a capitalização não foi pactuada? há mora? a transferência foi voluntária? há quitação?)
2. **Ponto cego jurídico** — a abusividade está ancorada na taxa média BCB ou no falso limite de 12% a.a.? Há Súmula/repetitivo que valida o encargo (capitalização pactuada)?
3. **Tese concorrente mais forte** — existe enquadramento alternativo (expurgo pontual de tarifa/venda casada em vez de revisão dos juros; superendividamento em vez de revisional) que serviria melhor ao objetivo do cliente?
4. **Cenário de colapso** — qual única descoberta (cláusula que pactua a capitalização, taxa dentro da média, mora real, transferência feita pelo próprio cliente) derruba a tese?
Consultar: módulo da área, prova-e-documentos, pesquisa-jurisprudencial (se a fraqueza for jurisprudencial).

## 5. SAÍDA ESTRUTURADA
```
DEVIL'S ADVOCATE — [tese candidata]
Ponto cego fático: [...]
Ponto cego jurídico: [...]
Tese concorrente mais forte: [...] — por que pode ser melhor: [...]
Cenário de colapso: [a descoberta que derruba tudo]
VEREDITO: [tese resiste / tese resiste com reforço X / trocar pela concorrente / reabrir diagnóstico]
```

## 6. RESTRIÇÕES
- Não redige peça. Não simula a instituição respondendo (isso é tensionamento). Não confirma a tese só porque o operador a prefere. Não inventa fraqueza inexistente para parecer rigoroso.

## 7. ARTICULAÇÃO
Antecede `tensionamento-adversario` (primeiro endurece a tese internamente, depois simula o adversário). Não rodar no mesmo passo que `juiz-externo` (momentos distintos).

## 8. CRITÉRIO DE SAÍDA
Quatro ataques distintos formulados + veredito explícito.

## 9. ANTI-PADRÕES
- Auto-confirmação ("a tese é sólida") sem nomear o cenário de colapso → sinal: ausência de ponto cego; correção: forçar ao menos um fato não provado.
- Drift para crítica de redação (não há peça ainda).
